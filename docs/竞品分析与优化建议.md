## 4. 优化机会洞察（核心）

### 4.1 玩法机制

> 设计透镜：**重弟子拟真度 + 全自动战斗 + 轻量放置**。三者统一为「让弟子有生老病死与传承的真实感，但全部自动结算，玩家只做高层决策不微操」——这正是鬼谷八荒/太吾的 AI 驱动 NPC 模式。拟真度来自系统涌现，而非玩家操作负担。

#### 4.1.1 弟子寿命死亡与自然流失【P0｜低改动】

**现状缺口**：`calculateLifespan` / `recomputeLifespan` 已计算寿命上限，`disciple.age`/`maxAge` 字段齐全，但全代码无 `age >= maxAge` 判定，弟子永生不死；同时无叛逃/还俗，弟子只能被玩家驱逐或试炼阵亡。宗门没有生老病死的真实感。

**优化方向**：
- 在 `nextMonth()` 年龄+1 后，补 `age >= maxAge` 判定 → 寿终正寝（转 `deadDisciples`，写宗门历史，触发追悼事件 feed）。
- 满意度连续 N 月 < 阈值（如 30）→ 概率叛逃/还俗，带贡献扣减与正邪度影响。
- 体质/境界影响寿命上限已由 `calculateLifespan` 体现，顺势让「长寿体质」「增寿丹药」产生真实价值。

**借鉴来源**：修仙家族模拟器「真实寿元 + 功德转生」、太吾「角色寿命有限强制代际规划」。
**与轻量放置的关系**：完全自动，玩家无需干预，只是让宗门有新陈代谢的真实感，反而强化「轻量放置」——挂机几个月回来，宗门已自然更迭。

#### 4.1.2 师徒传承系统【P1｜中改动】

**现状缺口**：`master`/`friends` 字段存在但无玩法逻辑，师徒关系形同虚设。

**优化方向**：
- 招收/手动指定师徒关系：师傅为弟子提供修炼速度加成（如 +10%~30% 视师傅境界），并每月传授功法心得（加速学习秘籍）。
- 师傅寿终/叛逃时，弟子触发「衣钵继承」事件：概率继承师傅功法/装备/部分贡献，并获「为师复仇/完成遗愿」等动机事件。
- 与 4.1.1 寿命死亡联动，形成「老一代凋零→新一代接班」的自然传承节奏。

**借鉴来源**：太吾绘卷世代传承系统、鬼谷八荒拜师收徒。
**拟真度收益**：弟子不再是无关联的数值卡，而是有师承脉络的「宗门族谱」，这是宗门题材区别于普通放置游戏的核心差异化。

#### 4.1.3 弟子关系网与涌现事件【P1｜中改动】

**现状缺口**：`friends` 字段无逻辑，弟子间无互动，宗门内部是静态的。

**优化方向**：
- 每月按概率生成关系：同门→好友/道侣/宿敌（基于境界、灵根、满意度匹配）。
- 关系影响行为：好友组队试炼有协同加成；宿敌同建筑减产且可能触发「内斗」事件；道侣可激活 4.1.4 子嗣。
- 关系网可视化：弟子详情页展示关系图谱（师徒/好友/道侣/宿敌），让宗门有「群像感」。

**借鉴来源**：太吾十类关系网 + 立场决定解法、鬼谷八荒 AI 驱动 NPC 社交。
**与全自动的关系**：关系生成与影响全部自动，玩家只看结果与事件 feed，不操作配对——拟真度来自系统，负担不来自玩家。

#### 4.1.4 道侣与子嗣（轻量血脉）【P2｜高改动｜长线】

**现状缺口**：无感情/婚姻/子嗣，弟子是「一次性消耗品」。

**优化方向**：
- 道侣关系（4.1.3 延伸）每月概率诞下子嗣，继承双亲灵根/天赋的混合（简化孟德尔）。
- 子嗣作为「宗门嫡传」自动培养，修炼速度有宗门加成，但需占用居所资源。
- 形成「宗门世家」长线叙事：数代后出现「某脉弟子皆出某祖师」的族谱感。

**借鉴来源**：修仙家族模拟器血脉遗传 + 跨代联姻育种（该品类最强差异化点）。
**定位说明**：这是最重度的拟真化，建议作为长线版本规划；轻量放置前提下，子嗣培养全自动，玩家只决定「是否鼓励道侣」政策。

#### 4.1.5 建筑随机事件【P1｜低-中改动】

**现状缺口**：建筑只有稳定产能，无随机事件，月度推进缺乏变数与叙事。

**优化方向**：
- 每月按建筑类型概率触发事件：丹堂「丹成异象」（增产/出稀有丹）、灵田「灵气暴动」（增产）/「灵草枯萎」（减产）、藏经阁「顿悟」（随机弟子突破进度+）、居所「走火入魔」（满意度暴跌/受伤）。
- 事件分吉凶，吉事件给小额奖励+叙事 feed，凶事件给可恢复的小损失+警示，避免纯惩罚。
- 与 4.1.1 寿命/4.1.3 关系联动：走火入魔可能触发弟子叛逃。

**借鉴来源**：了不起的修仙模拟器五行风水引发的建筑事件、缺氧确定性失败链。
**收益**：让月度「下一步」有期待感，缓解轻量放置的「无脑挂机」枯燥。

#### 4.1.6 失败终局与可追溯因果【P1｜中改动】

**现状缺口**：除飞升胜利外无任何终局，灵石长期破产只是告警，宗门永不灭亡，缺乏张力与「再来一局」动机。

**优化方向**：
- 宗门灭亡条件：连续 N 月灵石 < -阈值 / 在册弟子 = 0 / 声望归零。
- 灭亡时给「宗门覆灭复盘」报告：列出关键决策点（哪月过度扩张、哪次试炼团灭、哪笔维护费拖垮经济），借鉴缺氧「失败可追溯」。
- 与 4.1.5 事件、4.1.1 流失联动，形成「灵石紧张→削减维护→弟子不满→叛逃→战力下降→试炼失败→更穷」的死亡螺旋（可逆转，但有张力）。

**借鉴来源**：缺氧确定性失败 + 责任归因学习曲线、冰汽时代硬截止威胁。
**与轻量放置的关系**：失败是长程涌现而非突发，玩家有充分预警与逆转空间，不破坏放置体验。

#### 4.1.7 分支选择型随机事件【P1｜中改动】

**现状缺口**：`EventFeed` 仅展示通知，无玩家决策的事件，月度缺乏「选择题」乐趣。

**优化方向**：
- 每月概率弹出 1 个分支事件：天降异宝（争抢→得宝+结仇 / 让出→+声望）、邪修来犯（迎战→战力判定 / 妥协→失财保人）、弟子走火（强行镇压→可能伤亡 / 耗材救治→消耗丹药）。
- 每个选择有明确的收益/代价权衡，呼应冰汽时代「玩法即叙事」。
- 选择影响正邪度，与现有 karma 系统联动（正道选择+正邪度，魔道选择-正邪度但短期收益高）。

**借鉴来源**：冰汽时代法律树路径化抉择、太吾立场决定解法。
**收益**：给轻量放置补上「每月一个有意义的小决策」，既不增肝度又提升参与感。

#### 4.1.8 战斗反馈优化（保持全自动）【P0｜低改动】

**现状缺口**：用户选择保持全自动战斗，但当前全自动结算只有结果数字，缺乏过程感与策略可读性。

**优化方向**：
- 试炼/大比/围攻结算后，给「战报回放」：关键回合、暴击/闪避节点、战力对比曲线，让玩家「看懂为什么赢/输」。
- 战力公式透明化：弟子详情页展示战力构成（基础+装备+境界+状态），让玩家知道培养方向。
- 不引入手动操作，但让「全自动」变得「可读可优化」。

**借鉴来源**：了不起的修仙模拟器战斗数据透明化（重置版蜀山掌门的改进方向）。
**定位说明**：尊重用户「保持全自动」选择，仅在反馈层做加法，不动核心战斗逻辑。
