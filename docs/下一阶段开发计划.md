# 下一阶段开发计划

> 本文档规划修仙宗门管理游戏的下一个开发阶段，涵盖现有系统深化、新内容拓展、视觉升级和体验优化四个维度。

---

## 一、总体目标

在现有基础上全面提升游戏深度和体验，使游戏从"功能完整"走向"内容丰富、体验流畅、视觉精致"。

**核心原则**:
- 轻量放置定位不变，不增加不必要的操作负担
- 所有新系统与现有系统（弟子、建筑、经济、战斗）有机融合
- 每次迭代均衡包含玩法内容和体验优化

## 三、各方向详细方案

### 3.1 炼丹/炼器/制符深化系统

#### 现状
当前炼丹/炼器/制符只有简单的建筑产出，没有配方系统、品质差异、材料收集等深度玩法。

#### 改造方案

**配方系统**:
- 每个丹方/器方/符方有「基础材料 + 可选辅料」结构
- 配方可通过「探索获得」「宗门传承解锁」「大比奖励」等方式获取
- 未解锁的配方在对应面板显示为"???"，有线索提示

**品质系统**:
- 产出品质分为：凡品 → 良品 → 极品 → 仙品
- 品质受以下因素影响：
  - 弟子对应天赋（炼丹天赋/炼器天赋等）
  - 建筑等级
  - 辅料投入
  - 随机波动

**材料体系**:
- 已有特殊材料（20种）与基础材料（灵草/灵铁/符纸）形成配方树
- 高阶配方需要探索/游历获取稀有材料
- 稀有材料可交易的「黑市」系统（可选）

**操作流程**:
- 在对应面板选择配方 → 选择炼制弟子 → 选择辅料（可选）→ 开始炼制
- 炼制需要消耗一定回合数（1-3个月）
- 炼制完成时弹出结果通知

#### 涉及文件
- `src/types/pill.ts` / `artifact.ts` / `talisman.ts` — 扩展类型
- `src/data/pills.ts` / `artifacts.ts` / `talismans.ts` — 新增配方数据
- `src/components/PillsPanel.tsx` — 重构为配方炼制界面
- `src/utils/gameLogic.ts` — 新增炼制逻辑函数
- `src/store/gameStore.ts` — 新增炼制状态和 action

### 3.2 经济系统优化

#### 现状
灵石产出曲线在中期后可能溢出或枯竭，缺少市场波动。

#### 改造方案

**产出曲线调优**:
- 分析当前各阶段灵石收支数据，调整建筑产出公式
- 确保「前期紧缺、中期平衡、后期盈余但有大额支出」
- 新增「宗门扩张」大额支出途径（如扩张领地、建设护山大阵）

**物价波动**:
- 商店物品价格随市场供需微幅波动（±20%）
- 波动受以下因素影响：
  - 宗门出售/购买量
  - 外交关系（友好宗门有折扣）
  - 随机事件（如"灵草丰收季"降价）
- 自动交易规则增强：可设置「低于某价格时买入/高于某价格时卖出」

**新支出途径**:
- 护山大阵：消耗灵石维持，提供防御加成
- 宗门扩张：消耗灵石扩建宗门领地，解锁更多建筑位
- 弟子福利：主动发放灵石提升满意度

#### 涉及文件
- `src/domain/balance.ts` — 调整产出公式
- `src/data/shop.ts` — 添加价格波动因子
- `src/store/gameStore.ts` — 新增市场状态、护山大阵等
- `src/components/ShopPanel.tsx` — 增强自动交易规则配置

### 3.3 事件系统丰富

#### 现状
当前建筑事件池较小（每个建筑1-2个事件），分支选择事件约5种，缺少连锁事件。

#### 改造方案

**事件池扩充**:
- 每个建筑增加至3-5个事件
- 新增「季节事件」：春/夏/秋/冬各有特色事件
- 新增「弟子触发事件」：特定条件下由弟子触发（如「弟子X在修炼中顿悟」「弟子X与Y发生争执」）

**连锁事件**:
- 事件可以有后续分支，形成事件链
- 例如：「藏经阁古籍受潮」→ 选择修复 → 发现古籍中隐藏功法 → 解锁新功法
- 连锁事件存储在 `eventChains` 状态中，延迟触发

**事件影响深化**:
- 事件效果影响范围更大：可影响特定建筑、特定弟子群体、外交关系
- 事件可触发短时「宗门 buff/debuff」状态

#### 涉及文件
- `src/types/game.ts` — 扩展事件类型，新增连锁事件类型
- `src/utils/gameLogic.ts` — 扩充事件池，实现连锁事件逻辑
- `src/store/gameStore.ts` — 新增连锁事件处理
- `src/components/EventFeed.tsx` — 增强事件展示

### 3.4 弟子个性化

#### 现状
弟子目前只有根骨/灵韵/命数三维天赋和体质，缺少性格、偏好、个人故事线。

#### 改造方案

**性格特质**:
- 新增 `personality` 字段，取值如：勤勉/懒散/好斗/平和/贪婪/慷慨/孤僻/友善
- 性格影响：
  - 修炼速度微调（勤勉+5%）
  - 满意度变化倾向（贪婪弟子对灵石奖励更敏感）
  - 叛逃概率（孤僻弟子更容易叛逃）
  - 关系网生成偏好（友善弟子更容易交朋友）

**个人故事线**:
- 每个弟子生成时附带1-2条「背景故事」线索
- 特定条件下触发弟子专属事件
- 例如：「弟子X出身修仙世家」→ 家族被灭 → 触发复仇事件线

**喜好系统**:
- 弟子对特定丹药/功法有偏好
- 投其所好可提升满意度、修炼速度
- 厌恶则降低满意度

#### 涉及文件
- `src/types/disciple.ts` — 新增 personality, background, preferences 字段
- `src/utils/gameLogic.ts` — 生成性格、背景故事
- `src/components/DisciplesPanel.tsx` — 展示性格和背景
- `src/components/DiscipleStrip.tsx` — 性格图标标识

### 3.5 探索/游历系统

#### 现状
完全没有探索/游历功能，弟子只能待在宗门内。

#### 改造方案

**探索机制**:
- 在「活动面板」中新增「探索」功能
- 选择弟子 → 选择探索区域（宗门周边 → 野外秘境 → 上古遗迹）
- 探索消耗时间（1-6个月），期间弟子不在宗门
- 探索结果受弟子境界、天赋、运气影响

**探索产出**:
- 稀有材料（高阶丹药/法器所需）
- 功法秘籍（新增藏经阁藏书）
- 灵石、丹药等
- 特殊事件（遭遇散修、发现秘境、触发战斗）
- 负面结果（受伤、被困、一无所获）

**探索区域**:
- 宗门周边（安全，低收益，1个月）
- 妖兽森林（中等风险，中等收益，2个月）
- 古战场遗迹（高风险，高收益，3个月）
- 天外秘境（极高风险，极品收益，6个月）
- 新区域通过「探索获得地图碎片」解锁

#### 涉及文件
- `src/types/game.ts` — 新增探索区域、探索任务类型
- `src/utils/gameLogic.ts` — 探索结果生成逻辑
- `src/store/gameStore.ts` — 探索状态管理
- `src/components/ActivitiesPanel.tsx` — 集成探索功能
- `src/components/ExplorationModal.tsx` — 探索结果弹窗（新建）

### 3.6 宗门传承系统

#### 现状
宗门没有独特的流派/特色，所有宗门玩法相同。

#### 改造方案

**流派选择**:
- 游戏开局或宗门晋升时选择流派
- 流派示例：剑修流派（弟子战力+10%）、丹修流派（炼丹产出+20%）、阵修流派（防御+15%）
- 不同流派解锁不同的专属建筑/事件/功法

**宗门天赋树**:
- 消耗宗门贡献点/灵石解锁天赋节点
- 天赋树分支：修炼、战斗、经济、防御
- 关键节点提供质变效果（如「自动炼丹」）

**宗门声望技能**:
- 声望达到特定阈值解锁特殊能力
- 例如：名门正派（声望>500）→ 弟子招收效率+50%
- 邪道魔宗（声望<-300）→ 掠夺收益+50%

#### 涉及文件
- `src/types/game.ts` — 新增流派、天赋树类型
- `src/data/schools.ts` — 流派配置数据（新建）
- `src/store/gameStore.ts` — 流派状态、天赋解锁
- `src/components/RulesPanel.tsx` 或新建 `SchoolPanel.tsx`

### 3.7 天灾/宗门气运

#### 现状
缺少周期性大型事件，游戏节奏缺少起伏。

#### 改造方案

**周期性天灾**:
- 每10-20年触发一次大型天灾
- 类型：天劫雷暴（弟子受伤）、兽潮来袭（战斗事件）、灵脉枯竭（产出减半）、秘境开启（探索机遇）
- 天灾前有预警事件，给玩家准备时间

**宗门气运**:
- 新增 `sectFortune` 状态（-100 ~ 100）
- 气运受宗门行为影响（行善积德+、作恶-、大比夺冠+、弟子叛逃-）
- 气运影响事件概率（气运高 → 吉事多，气运低 → 凶事多）

**气运事件**:
- 气运极高时触发「天降祥瑞」（全属性提升）
- 气运极低时触发「宗门劫难」（强制事件）

#### 涉及文件
- `src/types/game.ts` — 新增气运、天灾类型
- `src/utils/gameLogic.ts` — 天灾触发逻辑
- `src/store/gameStore.ts` — 气运状态、天灾管理
- `src/components/EventFeed.tsx` — 天灾预警展示

### 3.8 视觉升级

#### 现状
当前 UI 风格偏简陋，缺乏统一的视觉语言和动效。

#### 改造方案

**色彩体系统一**:
- 建立修仙主题色彩系统：主色（深蓝/金色）、辅助色（青绿/赤红）、状态色
- 统一所有面板的配色方案，移除内联 style

**动效优化**:
- 页面切换增加淡入淡出/滑动过渡
- 数值变化（灵石、声望）增加数字滚动效果
- 事件通知增加弹入动画
- 月度结算增加过渡动画

**图标系统**:
- 统一使用 lucide-react 图标，替换文字按钮
- 为建筑、物品、境界等增加图标标识

**视觉细节**:
- 卡片阴影、圆角、边框统一
- 加载状态骨架屏
- 空状态插画

#### 涉及文件
- 全局 CSS 重构
- `tailwind.config.js` — 自定义色板
- 所有组件文件 — 统一视觉风格

## 五、技术实现要点

### 类型扩展原则
- 所有新增字段使用可选类型（`?`），确保向后兼容
- 存档兼容性：通过版本迁移或默认值处理旧存档

### 性能考量
- 探索系统：探索中的弟子不参与月度循环计算
- 连锁事件：使用队列存储，避免事件丢失
- UI 更新：使用 Zustand 的 selector 避免不必要的重渲染

### 测试策略
- 新逻辑函数编写单元测试（Vitest）
- 数值平衡调整后运行现有测试确保回归
- 视觉升级后人工检查各面板渲染正确性
